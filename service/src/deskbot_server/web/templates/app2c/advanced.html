02 · 必需配置

语音识别 ASR

机器人只通过 USB 把音频交给 PC；PC 默认调用火山豆包大模型流式 ASR，设备本身不保存凭证、也不直接访问云端。此处的 Provider 选择影响连通性测试与文本兼容路径；设备实时语音固定使用豆包流式（RTC 内硬编码），不随此选择切换。

[[ asr.configured ? '已配置' : '待配置' ]]
凭证边界
  1. 默认模式只需填写新版火山语音 API Key；不会复用大模型对话的 LLM_API_KEY，也不会把凭证下发到设备。
  2. PC 通过 WSS 连接火山豆包流式 ASR。保存后，核心 :9000 进程会在下一轮语音自动读取新配置。
  3. FunASR 为实验性选项、仅供本地测试：需自行安装可选依赖和准备 SenseVoice 模型，服务不会自动下载；设备实时语音仍固定走豆包流式，不受此选项影响。
